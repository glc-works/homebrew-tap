# GLC Works Homebrew Tap

Official Homebrew Tap for [GLC Works](https://github.com/glc-works) developer and literary tooling.

## Available Formulae

| Formula | Description | Install |
| :--- | :--- | :--- |
| **`okf`** | [Open Knowledge Fiction (OKF) Literary Studio CLI](https://github.com/glc-works/okf-studio) | `brew install glc-works/tap/okf` |

## Installation

Add this tap to your Homebrew installation:

```bash
brew tap glc-works/tap
```

Then install any formula:

```bash
brew install okf
```

Or install directly in a single command:

```bash
brew install glc-works/tap/okf
```

## Quick Verification

```bash
okf --version
okf --help
```
